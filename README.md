# API Notas de Texto

Este es un proyecto de práctica con Node.js y Express que permite crear, ver y eliminar notas. Las notas se almacenan en un archivo `notas.json`.

## Funcionalidades

- Crear notas
- Ver todas las notas
- Eliminar notas

## Tecnologías

- Node.js
- Express
- HTML, CSS y JavaScript
- JSON como almacenamiento local
